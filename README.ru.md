<h1 align="center">Claude Code Client</h1>
<p align="center"><code>v1.2.1</code></p>
<p align="center">
  <a href="README.md">English</a> | Русский
</p>

Удобный пакетный скрипт (`.cmd`) для установки, обновления и запуска официального CLI-клиента **Claude Code** в изолированном окружении в Windows.

Этот скрипт автоматизирует загрузку исполняемого файла `claude.exe`, изолирует файлы конфигурации от основной системы и предоставляет простой интерфейс настройки подключения к API.

---

## Ключевые особенности

1. **Портативный / изолированный режим (по умолчанию)**:
   - Скрипт может работать как в портативном режиме (переопределяя переменную окружения `USERPROFILE` на директорию `.claude` внутри директории скрипта), так и в обычном (непортативном) режиме, используя стандартный глобальный профиль пользователя Windows `%USERPROFILE%`. Это позволяет повторно использовать уже установленную версию Claude Code и её настройки.
   - В портативном режиме все глобальные кэши, настройки, авторизационные сессии и плагины Claude Code хранятся локально в директории скрипта, сохраняя глобальный профиль пользователя Windows чистым.

2. **Автоматическая установка**:
   - При первом запуске скрипт автоматически проверяет наличие последней версии Claude Code на серверах Anthropic, скачивает её с помощью `curl` и настраивает в нужных директориях.

3. **Гибкая настройка через `settings.ini`**:
   - При первом запуске скрипт предложит ввести следующие параметры:
     - `ANTHROPIC_BASE_URL` (по умолчанию используется официальный API: `https://api.anthropic.com`, но вы можете указать собственный прокси-сервер).
     - `ANTHROPIC_AUTH_TOKEN` (токен авторизации, полезен при использовании прокси или кастомных шлюзов).
     - `MODEL_NAME` (модель по умолчанию, например, `claude-sonnet-5`).
     - `UPDATE_BRANCH` (ветка для обновлений: `main` или `dev`).
   - Конфигурация сохраняется в локальный файл `resources\settings.ini` и автоматически загружается при последующих запусках.

4. **Система профилей**:
   - Файл `settings.ini` поддерживает именованные секции (профили), позволяющие хранить несколько конфигураций в одном файле.
   - Профиль можно указать через флаг `--profile`/`-p` с именем секции, либо выбрать интерактивно из списка, запустив `--profile` без аргумента.
   - Пример `settings.ini` с профилем:
     ```ini
      ANTHROPIC_BASE_URL=http://localhost:20128/v1
      ANTHROPIC_AUTH_TOKEN=sk-88cc84a27b153ff0-46fd23-2dcde1b5
      MODEL_NAME=openrouter/anthropic/claude-sonnet-5
      CLAUDE_DIR=%SCRIPT_DIR%.claude
      UPDATE_BRANCH=dev
      UPDATE_REPOSITORY=https://github.com/retopology/Claude-Code-Client
      UPDATE_MASK=raw/refs/heads/{BRANCH}/claude.cmd

      [Claude Opus 4.8]
      MODEL_NAME=openrouter/anthropic/claude-opus-4.8

      [Ollama Qwen3.5:9b]
      ANTHROPIC_BASE_URL=http://localhost:11434
      MODEL_NAME=qwen3.5:9b
     ```

5. **Обновление скрипта**:
   - Встроенный механизм обновления через флаг `--update-script`/`-u`.
   - Скрипт скачивает последнюю версию из указанного репозитория и ветки, сравнивает версии и при наличии обновления предлагает установить его.
   - Перед обновлением текущая версия сохраняется в `resources\old versions\`.

6. **Интеграция с системным PATH**:
   - При первой установке скрипт проверяет, добавлена ли его директория в системную переменную окружения `Path` пользователя.
   - Если нет, он предлагает добавить её автоматически, предварительно создавая резервную копию реестра в `resources\env_backup.reg` для безопасности.
   - Вы также можете вручную вызвать эту процедуру с помощью флага `--add-to-path`.

7. **Передача аргументов командной строки**:
   - Все аргументы, кроме перехватываемых скриптом (`--profile`/`-p`, `--update-script`/`-u`, `--add-to-path` и `--version-script`), напрямую перенаправляются базовому исполняемому файлу (например, `claude /fast` или `claude --help`).

## Структура каталогов после настройки

После первого запуска скрипт создаст следующую структуру каталогов (при использовании портативного режима по умолчанию):

```text
📁 /
├── 📄 claude.cmd       # Главный скрипт
├── 📁 .claude/         # Локальный USERPROFILE (изолированное окружение)
│   ├── 📁 .claude/     # Конфигурации, кэш, история сессий и плагины
│   └── 📁 .local/
│       ├── 📁 bin/                    # Активный бинарный файл claude.exe
│       └── 📁 share/claude/versions/  # Архив скачанных версий
└── 📁 resources/
    ├── 📁 old versions/      # Предыдущие версии скрипта
    ├── 📄 settings.ini       # Настройки подключения (URL, токен, модель, профили)
    ├── 📄 claude.exe         # Исполняемый файл Claude Code
    └── 📄 env_backup.reg     # Резервная копия реестра
```

## Требования

- Операционная система: **Windows 10 / 11**
- Предустановленная утилита `curl` (встроена во все современные версии Windows 10/11)
- Подключение к Интернету для загрузки исполняемого файла и взаимодействия с API

## Использование

### Первый запуск

1. Дважды кликните по `claude.cmd` или запустите его из консоли:
   ```cmd
   claude
   ```
2. Скрипт проверит наличие Claude Code. Если он уже установлен в системе, вам будет предложено использовать установленную версию или настроить портативный режим.
3. Скрипт предложит ввести параметры конфигурации. Вы также можете использовать настройки по умолчанию, просто нажимайте **Enter** при каждом запросе.
4. Дождитесь завершения загрузки `claude.exe` (если не выбрана уже установленная системная версия).
5. При появлении запроса на добавление директории в системный `PATH` введите `y` (да) или `n` (нет). Выбор `y` позволит вам вызывать клиент из любой директории в консоли с помощью команды `claude`.

### Обычный запуск

После настройки вы можете просто запустить скрипт, чтобы начать интерактивную сессию Claude Code:
```cmd
claude
```

Вы также можете передавать любые стандартные аргументы Claude Code:
```cmd
claude --version
claude /fast
```

### Профили

Запуск с указанием профиля:
```cmd
claude --profile work
claude -p work
```

Интерактивный выбор профиля:
```cmd
claude --profile
claude -p
```

### Интеграция с PATH вручную

Вы можете в любой момент добавить директорию со скриптом в системный PATH пользователя:
```cmd
claude --add-to-path
```

### Версия скрипта

Для быстрого вывода версии самого скрипта-клиента (без запуска самого Claude Code):
```cmd
claude --version-script
```

### Обновление скрипта

```cmd
claude --update-script
claude -u
claude -u dev
```
