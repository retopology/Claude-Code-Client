# Claude Code Client

Удобный пакетный скрипт (`.cmd`) для установки, обновления и запуска официального CLI-клиента **Claude Code** в изолированном окружении в Windows.

Этот скрипт автоматизирует загрузку исполняемого файла `claude.exe`, изолирует файлы конфигурации от основной системы и предоставляет простой интерфейс настройки подключения к API.

---

## Ключевые особенности

1. **Изолированное окружение (песочница / портативный режим)**:
   - Скрипт переопределяет переменную окружения `USERPROFILE`, указывая её на папку `claude` внутри директории скрипта.
   - Все глобальные кэши, настройки, авторизационные сессии и плагины Claude Code хранятся локально в директории скрипта, сохраняя глобальный профиль пользователя Windows чистым.

2. **Автоматическая установка**:
   - При первом запуске скрипт автоматически проверяет наличие последней версии Claude Code на серверах Anthropic, скачивает её с помощью `curl` и настраивает в нужных директориях.

3. **Гибкая настройка через `.env`**:
   - При первом запуске скрипт предложит ввести следующие параметры:
     - `ANTHROPIC_BASE_URL` (по умолчанию используется официальный API: `https://api.anthropic.com`, но вы можете указать собственный прокси-сервер).
     - `ANTHROPIC_AUTH_TOKEN` (токен авторизации, полезен при использовании прокси или кастомных шлюзов).
     - `MODEL` (модель по умолчанию, например, `claude-opus-4-6`, `claude-sonnet-4-6` и т. д.).
   - Конфигурация сохраняется в локальный файл `resources\.env` и автоматически загружается при последующих запусках.

4. **Интеграция с системным PATH**:
   - Скрипт проверяет, добавлена ли его папка в системную переменную окружения `Path` пользователя.
   - Если нет, он предлагает добавить её автоматически, предварительно создавая резервную копию реестра в `resources\env_backup.reg` для безопасности.

5. **Передача аргументов командной строки**:
   - Все аргументы, переданные в `ccc.cmd`, напрямую перенаправляются базовому исполняемому файлу (например, `ccc.cmd /fast` или `ccc.cmd --help`).

## Структура каталогов после настройки

После первого запуска скрипт создаст следующую структуру каталогов:

```text
📁 Ваша_Папка_Проекта/
├── 📄 ccc.cmd          # Стартовый скрипт
├── 📁 claude/          # Локальный USERPROFILE (изолированное окружение)
│   ├── 📁 .claude/     # Конфигурации, кэш, история сессий и плагины
│   └── 📁 .local/
│       ├── 📁 bin/                    # Активный бинарный файл claude.exe
│       └── 📁 share/claude/versions/  # Архив скачанных версий
└── 📁 resources/             # Ресурсы скрипта
    ├── 📄 .env               # Настройки подключения (URL, токен, модель)
    ├── 📄 claude.exe         # Скопированный исполняемый файл
    └── 📄 env_backup.reg     # Резервная копия реестра (создается перед изменением PATH)
```

## Требования

- Операционная система: **Windows 10 / 11**
- Предустановленная утилита `curl` (встроена во все современные версии Windows 10/11)
- Подключение к Интернету для загрузки исполняемого файла и взаимодействия с API

---

## Использование

### Первый запуск

1. Дважды кликните по `ccc.cmd` или запустите его из консоли:
   ```cmd
   ccc.cmd
   ```
2. Скрипт предложит ввести параметры конфигурации. Если вы хотите использовать настройки по умолчанию (официальный API Anthropic, модель `claude-opus-4-6` и отсутствие дополнительных токенов авторизации), просто нажимайте **Enter** при каждом запросе.
3. Дождитесь завершения загрузки `claude.exe`.
4. При появлении запроса на добавление директории в системный `PATH` введите `y` (да) или `n` (нет). Выбор `y` позволит вам вызывать клиент из любой папки в консоли с помощью команды `ccc`.

### Обычный запуск

После настройки вы можете просто запустить скрипт, чтобы начать интерактивную сессию Claude Code:
```cmd
ccc.cmd
```

Вы также можете передавать любые стандартные аргументы Claude Code:
```cmd
ccc.cmd --version
ccc.cmd --model claude-opus-4-6
```

## Ручное обновление и изменение конфигурации

- Если вам нужно изменить URL API, токен или модель по умолчанию, откройте `resources\.env` в любом текстовом редакторе и обновите значения:
  ```env
  ANTHROPIC_BASE_URL=https://api.anthropic.com
  ANTHROPIC_AUTH_TOKEN=ваш_токен_здесь
  MODEL=claude-opus-4-6
  ```
- Чтобы сбросить настройки и пройти шаги первоначальной конфигурации заново, просто удалите файл `resources\.env`.
